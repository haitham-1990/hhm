# مساعد نور التجريبي 0.1.0

تطبيق أندرويد تجريبي لفتح منصة نور داخل WebView ومساعدة المعلم في تعبئة نموذج التحضير.

## النسخة 0.1.0
- تسجيل الدخول إلى نور يتم بواسطة المعلم داخل صفحة نور نفسها.
- التطبيق لا يطلب كلمة المرور ولا يخزنها في كود التطبيق.
- قراءة عنوان الدرس الذي تعبئه شجرة المنهج تلقائيًا.
- اكتشاف مخرجات الدرس وتحديدها كلها.
- توليد تحضير محلي مجاني بدون API للدرس التجريبي، مع قالب عام لبقية دروس الرياضيات.
- تعبئة الاستراتيجيات والمصادر والمفاهيم والتهيئة وإجراءات الدرس والتقويمات وملاحظات الخطة الأسبوعية قدر الإمكان.
- لا يضغط زر حفظ تلقائيًا في هذه النسخة؛ يراجع المعلم ثم يحفظ بنفسه.
- زر «خروج» يمسح كوكيز جلسة نور من WebView.

## طريقة الاختبار
1. افتح التطبيق وسجل الدخول إلى نور.
2. اذهب إلى إضافة التحضير.
3. اختر الدرس من شجرة المنهج وانتظر ظهور العنوان تلقائيًا.
4. اضغط «فحص».
5. اضغط «كل الأهداف».
6. اضغط «تجهيز» لمعاينة المحتوى.
7. اضغط «تعبئة» ثم راجع الحقول واضغط حفظ في نور بنفسك.
