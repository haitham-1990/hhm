# مباراة المعرفة — Godot Professional Track

مسار جديد مستقل عن نسخ WebGL وUnity السابقة.

## الهدف
لعبة كرة قدم 3D تعليمية 6 ضد 6، بدون تحكم يدوي باللاعبين:
- الإجابة الصحيحة = استمرار الهجمة / تمريرة
- الإجابة الخاطئة = قطع الكرة وانتقال الاستحواذ
- بعد سلسلة تمريرات = سؤال تسديدة
- تسديدة / تصدٍ / هدف / احتفال / إعادة من المنتصف

## المحرك
Godot 4.6 — Mobile renderer — Android arm64.

## أول Vertical Slice
المشروع يبني الملعب والاستاد والكاميرا والكرة و12 لاعبًا عند التشغيل.
إذا كان `assets/player.glb` موجودًا يستخدم نموذج اللاعب المتحرك CC0؛ وإلا يوجد fallback هندسي للتطوير فقط.

## البناء
GitHub Actions يبني APK Debug مباشرة بدون Unity License.
