# MATH EDGE AI SCALPER v3 — الذهب M5 مع أربعة أطر تحليل
هذا إصدار تجريبي للسكالبينغ مزود بشبكة عصبية داخلية C#؛ لا يستدعي أي API خارجي.

## آلية القرار
- M5: توقيت الدخول + مؤشرات الزخم والحركة والحجم والتذبذب.
- M15: اتجاه قريب وتأكيد الحركة.
- H1: الاتجاه خلال الساعة.
- H4: السياق المتوسط.
- D1: الاتجاه الأوسع.
- يستخدم جميع الإطارات **بشموع مغلقة فقط**، مع محاذاة تاريخية لكل شمعة M5 لتجنّب تسرب معلومات مستقبلية أثناء التدريب.
- شبكة عصبية 18 مدخلاً × 12 خلية × 3 مخرجات (شراء / انتظار / بيع).
- البيانات تقسم زمنياً إلى تدريب ثم معايرة ثم تحقق لاحق مستقل. عدد صفقات التحقق ومعدل النجاح ومعامل الربح جزء من شروط السماح بالتداول؛ لا تزال الإشارات قد تكون قليلة أو غير مؤهلة.
- لا يشترط اتفاق الفريمات الأربعة جميعاً؛ يستخدم وزنًا للاتجاهات مع مؤشر RSI ودعم اتجاه M5.

## الإعدادات المقترحة للتجربة
السوق XAUUSD، فاصل M5، حساب Demo على cTrader Cloud.
- Enable Orders = false (إشارات فقط أولاً)
- Allow Live Account = false
- Risk % Per Trade = 0.25%
- Daily Equity Loss Limit = 2%
- Instance Drawdown Limit = 5% (يُعاد احتساب ذروته عند إعادة تشغيل المثيل)
- Max Entries per UTC Day = 8
- Cooldown Minutes = 10
- Max Trade Duration = 30 دقيقة؛ يراقبها Timer على مستوى الدقيقة
- SL = 1.5 × ATR(14) على M5، TP = 1.4 × مسافة SL
- Maximum Spread / ATR = 0.12

## خطوات التشغيل
1. أوقف البوت السابق ولا تشغّله بالتوازي.
2. افتح `MATH_EDGE_AI_SCALPER_V3.algo` في cTrader.
3. اختر Demo / XAUUSD / M5 / Cloud.
4. راقب سجلات Higher timeframes و CALIBRATION و MODEL و ML M5.
5. إذا ظلت VALIDATED=False، فهذا منع متعمد للصفقات. لا تُلغِ بوابة التحقق.
6. بعد اختبار تاريخي واقعي على cTrader (سبريد وعمولات وانزلاق) واختبار Demo الأمامي، يمكن تقييم تشغيل الأوامر على Demo فقط.

## تنبيهات
- هذه شبكة عصبية صغيرة تتعلم من بيانات الأسعار داخل البوت، وليست نموذج GPT.
- النجاح في تجميع الملف لا يثبت ربحية البوت أو سلامة تنفيذ جميع الأوامر في ظروف الوسيط.
- اختبارات التحقق المدمجة تقديرية وليست Backtest تنفيذيًا كاملاً.
- منع تداول حساب Live مفعل افتراضياً؛ لا تستخدم حسابًا حقيقيًا قبل إثبات جدوى مستقلة.
- يغلق البوت صفقاته آلياً عند تجاوز مدة الاحتفاظ إذا كانت أوامر التداول مفعلة، وقد يؤدي انزلاق السوق لخسارة أكبر من المخطط.
